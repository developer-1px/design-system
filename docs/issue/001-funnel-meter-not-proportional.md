# 001 — Funnel 미터 바 너비가 실제 값과 비례하지 않음

- **라우트:** `/analytics` (Growth overview)
- **심각도:** 중 (데이터 시각화 신뢰성)
- **유형:** 구성(시각화 정합)

## 현상 (화면 실측)

우측 `Funnel` 카드의 막대 4개를 확대 측정한 결과, 막대 길이가 표시 수치와 비례하지 않습니다.

| 단계 | 표시 값 | 값/최댓값(12,480) | 실측 막대 채움 |
|------|--------:|------------------:|---------------:|
| Visited pricing | 12,480 | 100% | **약 81%** (가득 차지 않음) |
| Started trial | 2,960 | 23.7% | 약 47% |
| Invited teammate | 1,218 | 9.8% | 약 31% |
| Converted | 486 | 3.9% | 약 18% |

- 깔때기 최상단(가장 큰 값)인데도 막대가 **가득 차지 않아** 기준선이 모호합니다.
- 막대 길이가 선형 비율이 아니라 대략 `√value` 곡선을 따릅니다 → 단계별 전환 하락폭이
  실제보다 완만하게 보여, 막대 길이로 전환율을 가늠하면 오인합니다.

## 원인 (소스)

`src/pages/WorkspacePages.tsx`

```ts
const funnelRows = [
  ['Visited pricing', '12,480', 82],
  ['Started trial',    '2,960', 48],
  ['Invited teammate', '1,218', 31],
  ['Converted',          '486', 18],
] as const
```

미터 퍼센트(82/48/31/18)가 표시 값과 **독립적으로 손으로 입력**되어 있습니다.
값과의 산술 관계가 없으므로 값을 바꿔도 막대가 따라가지 않습니다.

## 제안

- 미터 퍼센트를 값에서 파생: `meter = Math.round(value / rows[0].value * 100)`
  → 최상단 100%, 나머지가 실제 비율로 단조 감소.
- 작은 값의 가독성이 목적이라면 `√` 스케일을 **의도적으로** 쓰되,
  그 사실을 라벨/주석으로 표기하고 최상단은 100%로 정규화.
- 어느 쪽이든 "표시 숫자 ↔ 막대 길이"가 일관되도록 단일 소스에서 계산.
